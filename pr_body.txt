This PR completes the comprehensive Arabic translation for the Instructor Portal and resolves multiple UI layout issues introduced by Right-To-Left (RTL) rendering.

### ?? Localization (i18n)
- **Instructor Tabs**: Fully localized the InstructorEngagementTab, InstructorFinancialsTab, and InstructorReviewsTab, translating all headers, buttons, empty states, and dynamic statistics.
- **Analytics Charts**: Added proper mapping for month names inside the Recharts tooltips so they dynamically display Arabic months.
- **Dynamic Content**: Safely replaced hardcoded English text in API responses (e.g., Transaction status badges and prefixes like 'Course Sale - ') using dynamic i18n substitution.
- **Empty States**: Translated all edge-case strings, such as 'You haven't created any courses yet...', to ensure punctuation aligns correctly with RTL formats.

### ?? UI & RTL Styling Fixes
- **Table Border Radius**: Replaced hardcoded physical CSS properties (like border-top-left-radius) on table cells with modern CSS Logical Properties (e.g. border-start-start-radius, border-start-end-radius). This natively fixes the hover and border highlighting for .analytics-row regardless of LTR/RTL direction.
- **Shadow Standardization**: Updated the ConfirmModal cancel button and other portal buttons to strictly follow the internal design system's glass-card specification (inset 0 4px 12px rgba(0, 0, 0, 0.5)).
- **Loading Screens**: Fixed the FullPageLoader component rendering with generic backgrounds by forcing it to inherit the correct dark navy theme (var(--bg-main)) via parent data-role wrappers across the Instructor, Admin, and Student portals.
